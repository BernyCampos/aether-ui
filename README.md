# Aether UI · Atmosphere

A refined, celestial-inspired **theme for Pelican Panel**. Aether Atmosphere combines minimalist glass cards, soft blur, a calm atmospheric background and optional animated particles—without replacing Pelican's native Filament components or server controls.

**Version:** 0.4.0 · **Requires:** Pelican Panel **1.0.0-rc.4** · **Plugin category:** `theme`

[Download](https://github.com/BernyCampos/aether-ui/releases/tag/v0.4.0) · [Installation help](docs/TROUBLESHOOTING.md) · [Report an issue](https://github.com/BernyCampos/aether-ui/issues)

## Features

- **Quiet glass design:** translucent cards, restrained shadows, subtle borders and blurred navigation in dark and light mode.
- **Atmosphere effects:** local wallpaper and optional, slow CSS-only particles; reduced-motion and reduced-transparency preferences are respected.
- **Persistent settings:** colors, typography, spacing, cards, effects, console appearance and text branding. Existing preferences are retained when upgrading.
- **Native integration:** the official `HasTheme` selector, Filament interfaces and Pelican file/console actions remain intact.

## Installation

1. Make a backup of your panel and existing Aether settings.
2. Download **`aether-ui-0.4.0.zip`** from [Releases](https://github.com/BernyCampos/aether-ui/releases/tag/v0.4.0). Do not import the source ZIP.
3. In **Administration → Plugins**, import/install the ZIP, then select **Aether UI** in Pelican's theme picker.
4. Customize the appearance from the plugin's **Settings** panel. Particle effects are under **Effects**.

**Compatibility:** v0.4.0 targets Pelican **1.0.0-rc.4**. For Pelican rc.3, use Aether v0.3.0; for rc.2, use v0.2.4. No Pelican core changes or new migrations are required.
